Applyエラー / Apply Error / 反映处理错误

日本語：編集内容の反映処理ができませんでした。

English：The edited workbook could not be applied.

中文：无法执行编辑内容反映处理。

原因 / Reason / 原因

{% if lang == "zh" %} 文件名不一致、文件损坏、或Apply对象错误。 {% else %} ファイル名不一致、ファイル破損、またはApply対象ファイル誤りの可能性があります。 {% endif %}

確認してください / Please check / 请确认

  1. ファイル名を変更していないか確認してください。 / Please check that the file name has not been changed. / 请确认文件名没有被更改。
  2. ファイル名末尾に「(1)」「(2)」が付いている場合は、元のファイル名に戻してください。 / If “(1)” or “(2)” was added, restore the original file name. / 如果文件名末尾带有“(1)”或“(2)”，请恢复为原始文件名。
  3. 分からない場合は、最初からGenerateをやり直してください。 / If unclear, run Generate again from the beginning. / 如果不清楚，请从Generate重新开始。
