{% if lang == "zh" %} 关于翻译方式
・上下文翻译：将整个单元格一并交给翻译引擎。考虑前后关系，误译较少。
・分割翻译：把单元格内容分段后逐段翻译。速度快但会丢失上下文，短词易误译。
例（中→日）：「第2工厂 3楼」分割时会变成「いいえ。2工場 3建物」，上下文翻译则为「第2工場 3階」。
⚠️ 中文→日语 使用分割翻译时，任何引擎都容易出现误译，建议使用上下文翻译。
※ DeepL 仅支持上下文翻译。 {% else %} 翻訳方式について
・文脈翻訳：セル全体をまとめて翻訳エンジンに渡す方式。前後関係を踏まえるため誤訳が少ない。
・分割翻訳：セル内を区切って部分ごとに翻訳する方式。速いが文脈を失い、短い語が誤訳されやすい。
例（中→日）：「第2工厂 3楼」→ 分割では「いいえ。2工場 3建物」と崩れ、文脈では「第2工場 3階」と正しく訳されます。
⚠️ 中国語→日本語で分割翻訳を行うと、どの翻訳機でも誤訳が多発する傾向があります。文脈翻訳の使用を推奨します。
※ DeepL は文脈翻訳のみ対応です。 {% endif %}
{% if lang == "zh" %} ⚠️ DeepL 仅支持「上下文翻译」。选择 DeepL 时，翻译方式将自动设为上下文翻译（无法选择分割翻译）。 {% else %} ⚠️ DeepL は「文脈翻訳」のみ対応です。DeepL を選ぶと翻訳方式は自動的に文脈翻訳になります（分割翻訳は選べません）。 {% endif %}
