{% if lang == "zh" %} ・上下文翻译：将整个单元格一并交给翻译引擎。考虑前后关系，误译较少。
・分割翻译：把单元格内容分段后逐段翻译。速度快但会丢失上下文，短词易误译。
例（中→日）：「第2工厂 3楼」分割时会变成「いいえ。2工場 3建物」，上下文翻译则为「第2工場 3階」。
注意：中文→日语 使用分割翻译时，任何引擎都容易出现误译，建议使用上下文翻译。DeepL 仅支持上下文翻译。
注意：Google 翻译无法保留单元格内的换行（换行可能被删除，多行会合并为一行）。如需保留换行，请选择 Amazon 或 DeepL。 {% else %} ・文脈翻訳：セル全体をまとめて翻訳エンジンに渡す方式。前後関係を踏まえるため誤訳が少ない。
・分割翻訳：セル内を区切って部分ごとに翻訳する方式。速いが文脈を失い、短い語が誤訳されやすい。
例（中→日）：「第2工厂 3楼」→ 分割では「いいえ。2工場 3建物」と崩れ、文脈では「第2工場 3階」と正しく訳されます。
注意：中国語→日本語で分割翻訳を行うと、どの翻訳機でも誤訳が多発する傾向があります。文脈翻訳の使用を推奨します。DeepL は文脈翻訳のみ対応です。
注意：Google 翻訳は、セル内の改行を保持できません（改行が削除され、1行にまとまる場合があります）。改行を維持したい場合は Amazon または DeepL をお選びください。 {% endif %}
